# LexusSMS

Frontend UI + Vercel API proxy scaffold.

## Deploy
1. Upload this project to GitHub.
2. Import into Vercel.
3. Add environment variables:
   - API_BASE_URL
   - API_KEY
4. Do NOT prefix secret variables with NEXT_PUBLIC_ or VITE_.

## Important
The included API route is a scaffold. Replace `/api/v1/traffic` and authorization format with the exact provider documentation. Keep provider secrets server-side.
